# 对话归档

2026-10-11。对话归档属于 Core 的可恢复持久化状态。应用提供操作入口和列表展示，不维护第二份会话状态。

`Conversation.archived_at` 为可空 UTC 时间，空值表示未归档。既有数据和未提供此字段的可移植记录默认未归档。归档不删除对话，不改变角色、消息、活动时间、记忆/NSG 注入范围或来源，也不停止自动维护。恢复继续使用原身份及历史。

## 本机管理接口

- `GET /v1/conversations?space_id=<UUID>`：全部对话，保持原行为。
- 增加 `archived=false`：仅未归档；`archived=true`：仅归档。
- `POST /v1/conversations/<UUID>/archive`：`{"space_id":"<UUID>","archived":true}` 归档，`false` 恢复，返回当前完整对话。只接受这两个字段，拒绝其他空间的资源及不存在的对话。

归档时间由 Core 生成；重复归档不刷新时间，重复恢复保持空值。SQL 事务只修改归档字段，并返回同一事务内读取的结果；重命名、追加消息、角色切换不得用旧快照覆盖此字段。MOC 导出和空间迁移保留归档状态，资产清点不排除归档对话。

这些是本机管理 API，不扩展稳定产品 wire；宿主必须在已授权的个人空间内通过窄适配器调用。永久删除沿用其独立生命周期要求，不以归档代替删除，也不把归档恢复入口包装为永久删除已完成。
