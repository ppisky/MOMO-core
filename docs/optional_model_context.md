# 模型未声明上下文长度与路由参数

Web 接入需求（2026-10-09）：模型登记允许不声明上下文长度，null 与省略均表示未知，0 无效。ConfiguredModel 的 context_window 改为 Option<usize>；显式值保留 1024–16000000 的契约范围。内部预算在未知时使用保护性估计 8192，若显式最大输出需要更大预算则至少留一个输入 token；估计不回写为模型声明值。

功能模型路由支持额外 parameters 对象，与主请求一样交由个人 Space 的 RequestOverridePolicy 管理；top_p 与温度/最大输出依既有类型字段管理。该对象不能绕过协议保留字段校验。连接存储仍由宿主所有，内核不接管 Web 参数组或界面配置。
