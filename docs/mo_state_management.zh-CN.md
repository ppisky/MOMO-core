# MO State 本机管理视图

2026-10-11。应用需要查看状态操作、场景、约束和实际注入审计。管理数据由 Core 提供，应用不维护第二套状态日志。

`GET /v1/mo-state/management?space_id=<UUID>` 返回 version=1、目标空间、运行状态及最近 20 次状态操作，按更新时间倒序。查询只读，不唤醒投影、模型或自动维护。记录包含原快照和该次已完成回复的最小状态诊断，不返回完整回复、请求正文或模型凭据。

回复完成时在原 SQLite 事务中将状态操作与回复记录关联。管理视图读取保存的注入模式及最终 state section 审计；不根据当前策略反推历史。新关联列对旧数据默认为空，旧记录仍可查看原快照，但实际注入审计显示为未知。

状态输入审计增加检索子集的记录标识、类型、来源 Space 与状态资格，继续使用已捕获、经过资格治理的输入；它不是逐规则的证据映射，不创建新事实。

派生 DDM 的查询和重置继续复用既有 `/v1/mo-state/ddm-profile`；状态契约和运行策略保持已有接口。管理接口属于受信任本机控制面，宿主必须按已授权个人空间提供白名单适配。
