# Contributing to MOMO Core

[简体中文](#简体中文)

## Issues

Issues are open for reproducible bugs and concrete design proposals.

Before opening an Issue:

1. Search existing Issues and documentation.
2. Identify the affected release or commit.
3. Provide the operating system, architecture, Rust version, and affected component.
4. For bugs, include a minimal reproduction plus expected and actual behavior.
5. For proposals, begin with the problem or use case and describe compatibility or data impact.
6. Remove API keys, credentials, private conversations, character data, prompts, logs, and private paths.

## Pull requests

Pull requests are temporarily paused while Core interfaces and specifications are being stabilized. New PRs are automatically closed with a link back to the Issue process. Please open an Issue before preparing code.

## 简体中文

### Issues

Issues 用于反馈可复现问题或提出具体设计建议。

创建 Issue 前请：

1. 搜索现有 Issues 和文档，避免重复。
2. 填写受影响的版本标签或 commit。
3. 提供操作系统、架构、Rust 版本和受影响组件。
4. 问题报告需包含最小复现、预期行为和实际行为。
5. 功能建议需先说明问题或使用场景，并说明兼容性与数据影响。
6. 删除 API Key、凭据、私有对话、角色数据、提示词、日志和私有路径。

### Pull requests

Core 的接口和规范仍在稳定阶段，目前暂不接收 Pull Request。新 PR 会收到说明并自动关闭。准备代码前请先创建 Issue。
